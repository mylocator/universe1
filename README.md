# MyLocator Universe - Master Control Panel

An immersive, high-performance domain ecosystem navigator built with React, Vite, and Tailwind CSS.

## 🚀 Tech Stack
- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite 6](https://vitejs.dev/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Animation**: [Motion](https://motion.dev/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **AI Core**: [Google Gemini API](https://ai.google.dev/)

## ✨ Features
- **Interactive Universe**: Horizontal parallax scrolling of 200+ domain nodes.
- **Master Directory**: High-density grid view for rapid ecosystem scanning.
- **AI Core Assistant**: Integrated Gemini-powered chat for ecosystem insights.
- **Control Locator Hub**: Visual search path and pulsing feedback for cluster discovery.
- **Dual Theme Support**: Seamless transition between Dark (Cosmic) and Light (Clean Utility) modes.
- **Immersive Audio**: Procedural sound effects for UI interactions.
- **Smooth Navigation**: Global smooth scrolling and "Back to Top" functionality.

## 🛠️ Getting Started

### Prerequisites
- Node.js 18+
- npm

### Installation
1. Clone the repository:
   ```bash
   git clone <your-repo-url>
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Set up environment variables:
   - Create a `.env` file based on `.env.example`.
   - Add your `GEMINI_API_KEY`.

### Development
Run the development server:
```bash
npm run dev
```

### Build
Generate a production-ready build:
```bash
npm run build
```
